# FACN — Escola de Condução 🚗🌸

Website institucional oficial da **FACN (Escola de Condução)** em Angola. 
Formando condutores com segurança e responsabilidade.

## 🚀 Funcionalidades
- Design responsivo (Mobile-First) inspirado no flyer oficial (fundo rosa e elementos florais).
- **PWA (Progressive Web App):** Pode ser instalado no telemóvel e funciona offline.
- **Modal de Inscrição:** Formulário interativo com upload de foto e BI, integrado com o WhatsApp Business da escola.
- **Otimização Mobile:** Animações pesadas (parallax e pétalas) são desativadas automaticamente em telemóveis para poupar dados e bateria.
- Pagamentos suportados: Multicaixa Express e Referência Bancária.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Variáveis, Flexbox, Grid, Animações)
- JavaScript (Vanilla)
- PWA (Manifest & Service Worker)
